Telnet Commands¶

The following commands can be used to debug Node Controllers via Telnet:

Command Description
V / v prints the Node Name Firmware Version Stamp, IP and MAC addresses
i forces the node to report its UID to the server
b conduct a OSC broadcast test
m conduct a OSC multicast test
u conduct a OSC unicast test
R force a restart in 5 seconds
F force a node to forget its identity
I reset I2C
G / g clear the Node Controllers Logic Graph
D / d cycle through the levels of debug prints
p print a log of actuator positions
P print a log of logic block ID's and heap
S / s pause the graph execution
