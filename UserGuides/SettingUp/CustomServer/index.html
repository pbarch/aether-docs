Custom Server¶

Cloning Aethers Testbed-v4 Repository from Github¶

Ask for access to https://github.com/pbarch/testbed-v4 and clone it with git clone https://github.com/pbarch/testbed-v4

Setting Up Node.js & NPM¶

Nodejs is used for running the server and firebase database.

To easily manage Nodejs version we reccomend installing Node Version Manager (NVM). With NVM installed you can use nvm install --lts to install the latest long term support version of Nodejs and NPM.

Alternatively you can directly install a version of nodejs and npm from https://nodejs.org/en/download/prebuilt-installer if desired.

Once Nodejs and npm are installed, open a terminal in the testbed-v4\server folder and install the dependencies required to run the Aether Server with:

npm install

Note

The firebase emulator also requires the Java SDK (version 21 or above) to be installed. You can find an installer for your platform onOracles Java Downloads Page

Running the Server.¶

In the testbed-v4\server folder, run node server.mjs to start the server. Once the server is running you can access Aether locally at http://localhost:3022/ or on your network at http://[YOUR IP ADDRESS]:3022

Configuration¶

You can modifiy the default IP addreses for external systems (Light, Sound, Projection etc.) as well as setting related to the firebase database in the aether_default.env file.
